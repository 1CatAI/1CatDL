# 多节点执行

控制器保留唯一业务数据库与钱包。实例创建时固定 `node_id`，不把旧实例或私有磁盘迁移到新机器。
槽位与 SSH endpoint 唯一约束按节点分组；同一客户最多运行一台 GPU 实例的限制仍是全平台的。

`RENTAL_NODES_CONFIG` 指向 root-only JSON 数组；每项包含 `id`、`enabled`、`host`、`port`、`user`、`identity_file`、`known_hosts`、`public_ports` 和 `budget`。
私钥留在控制器的 `/etc/1cat-rental/keys`，不提交仓库；主机公钥必须先带外核实。

节点服务 `node_agent.py serve` 只监听 Unix socket。专用 SSH 用户仅允许固定的 `node_agent.py client` 命令，限制来源地址、禁止 PTY/转发/用户命令，不开放公网管理 API。
节点配置 `/etc/1cat-node/node.json`，root-owned，包含经过验收的镜像、PCI 地址、只读公共盘、私有盘位置、`control_root`、`state_root`、容量和可用开关。

节点持久化资源预留与 generation：相同代次的启动只执行一次，停止或删除后保留墓碑，过期请求不能重建实例；新的开机必须在旧硬件已回收后使用新代次。
远程请求超时不代表关机，不释放卡。75 秒运行租约失去续约后触发关机，宽限 20 秒后强制关闭；进行中的有限时长主机操作结束后执行回收。
控制器只计费到最后一次确认运行的时间，节点离线不会继续无限累计算力费。无法确认的时间可能少计，不向客户补收没有证据的算力费。持久数据盘的保留费用规则不变。

SSH 数据流由每个节点的本地转发器直接接该节点的 1CatTunnel，不绕行控制器。公共模型每机独立副本、客户只读；不共享 SQLite，不把客户私有数据放入公共模型目录。

上线门槛：模拟故障测试、真实远程创建/开机/SSH/计算/计费/停止/回收验证、公共盘完整性与只读验证、公网端口检查，全部通过后才在控制器配置 enabled=true。
代码回滚不回滚业务数据库；出现远程节点实例后禁止回滚到单机后端，可以仅回滚 UI。
