1CAT PUBLIC DATA /shared

This is a public, host-enforced read-only library shared by rental instances.
Models and datasets will be published by the administrator.

Do not store private files, credentials, training outputs or caches here.
Use your private /data disk, when purchased, or your home directory for writes.
Model loading tools should read local files from /shared and write their caches
and lock files to a separate private directory.

All instances share the same files and storage bandwidth. RAID0 is not a backup.
The public library is independent of your optional, billable private data disk.
